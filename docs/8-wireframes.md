## 1. 디자인 가이드라인 (Tailwind CSS 기반)

본 프로젝트는 Tailwind CSS를 활용하여 일관된 시각 언어를 유지한다.

### 1.1 디자인 토큰 (Design Tokens)

| 구분 | 역할 | Tailwind 클래스 예시 |
|------|------|-------------------|
| **Primary** | 브랜드 컬러, 주요 액션 | `bg-blue-600`, `text-blue-600` |
| **Secondary** | 보조 액션, 취소 | `bg-slate-200`, `text-slate-700` |
| **Danger** | 기한 초과(OVERDUE), 삭제, 에러 | `bg-rose-500`, `text-rose-600`, `border-rose-500` |
| **Success** | 완료(COMPLETED), 성공 메시지 | `bg-emerald-500`, `text-emerald-700` |
| **Surface** | 배경, 카드, 입력창 | `bg-slate-50` (전체 배경), `bg-white` (카드/폼) |
| **Text** | 기본 가독성 | `text-slate-900` (제목), `text-slate-500` (설명/메타) |
| **Shadow** | 계층 구조 구분 | `shadow-sm` (카드), `shadow-lg` (모달) |

### 1.2 공통 인터랙션 패턴 (SC-01 ~ SC-16 반영)

- **성공 피드백 (Success Toast)**: 화면 상단 중앙에 일시적으로 노출 (`bg-emerald-50 text-emerald-800 border-emerald-200`).
- **에러 피드백 (Field Error)**: 입력 필드 하단 빨간 텍스트 (`text-rose-600 text-xs`) 및 필드 테두리 강조 (`border-rose-500`).
- **로딩 상태 (Skeleton/Spinner)**: 버튼 클릭 시 `opacity-50` + `cursor-not-allowed` 및 중앙 `animate-spin` 아이콘.
- **삭제 확인 (Confirm)**: 중요한 삭제 작업(SC-13, 14)은 반드시 모달을 통해 재확인.

## 2. WF-01: 인증 페이지 (로그인 & 회원가입)

### 설계 의도
- **페르소나 B (가정주부)**를 고려하여 모바일 터치 타겟(최소 44px)을 충분히 확보.
- **페르소나 A (개발자)**를 위해 `Tab`키 순서를 논리적으로 배치하여 빠른 입력 지원.

## 3. WF-02: 메인 대시보드 (반응형 레이아웃)

- **사이드바 고정**: 카테고리 간 빠른 전환 (페르소나 A).
- **여백 활용**: 가독성을 위한 충분한 `padding-8`.

### 3.2 모바일 (320px ~ 640px) - 직관성 강조

- **FAB (Floating Action Button)**: 우하단에 배치하여 한 손 조작성 강화 (페르소나 B).

## 4. WF-03: 할일 카드 (상태별 시각적 구분 개선)

할일의 상태(PENDING, COMPLETED, OVERDUE)를 텍스트뿐만 아니라 색상과 형태(Affordance)로 명확히 구분한다.

### PENDING (대기중)
- **스타일**: `bg-white`, `border-slate-200`.
- **특징**: 기본적인 형태. 마감일이 다가올수록 텍스트 강조.

### COMPLETED (완료)
- **스타일**: `bg-slate-50`, `opacity-60`.
- **특징**: 제목 및 설명에 취소선(`line-through`), 체크박스 선택됨. 성공 배지(`emerald`).

### OVERDUE (기한 초과) - **강조 방식 개선**
- **스타일**: `border-l-4 border-rose-500`, `bg-rose-50/30`.
- **아이콘**: 제목 앞에 경고 아이콘(`!`) 또는 `🚨` 배치.
- **마감일**: "어제까지", "2시간 경과" 등 **상대 시간** 강조 표시 (페르소나 B 니즈 반영).

```
+------------------------------------------------------------------------------+
| [ ]  코드 리뷰 프로세스 개선                         [ 대기중 (slate) ]      |
|      (o) 업무  |  📅 2026-05-01 (내일)                                [/] [x] |
+------------------------------------------------------------------------------+

+------------------------------------------------------------------------------+
| [v]  ~~주간 장보기 완료~~                            [ 완료 (emerald) ]      |
|      (o) 가사  |  📅 2026-04-25                                      [/] [x] |
+------------------------------------------------------------------------------+

!------------------------------------------------------------------------------+
| [ ]  🚨 세금 신고 마감 (중요)                        [ 기한초과 (rose) ]     |
|      (o) 개인  |  📅 2026-04-20 (3일 경과!)                          [/] [x] |
+------------------------------------------------------------------------------+
```

## 5. WF-04: 할일 생성/수정 모달 (입력 가이드 강화)

### 설계 의도
- 마감일 설정 시 시간대까지 명확히 입력할 수 있도록 구성.
- 카테고리 선택 드롭다운에 "미분류" 옵션을 기본으로 제공.

```
+------------------------------------------------------------+
|  새 할일 추가 (또는 수정)                          [ X ]   |
+------------------------------------------------------------+
|                                                            |
|  제목 *                                                    |
|  +------------------------------------------------------+  |
|  | 할일 제목을 입력하세요 (예: 우유 사기)               |  |
|  +------------------------------------------------------+  |
|                                                            |
|  상세 설명                                                 |
|  +------------------------------------------------------+  |
|  | [ Textarea 영역 ]                                    |  |
|  +------------------------------------------------------+  |
|                                                            |
|  카테고리                       마감일                     |
|  +-----------------------+     +------------------------+  |
|  | [ 미분류 v ]          |     | 2026-05-01 [ 18:00 ]   |  |
|  +-----------------------+     +------------------------+  |
|                                (i) 설정하지 않으면 기한초과 |
|                                    가 되지 않습니다. (BR-08)|
|                                                            |
|                    [ 취소 ]  [ 저장하기 (bg-blue-600) ]     |
|                                                            |
+------------------------------------------------------------+
```

## 6. WF-05: 삭제 확인 모달 (데이터 무결성 안내)

### 카테고리 삭제 확인 (SC-14 반영)
카테고리 삭제가 하위 할일에 미치는 영향(BR-05)을 명확히 고지하여 사용자 실수를 방지한다.

```
+------------------------------------------------------------+
|  ⚠️ 카테고리 삭제                                   [ X ]   |
+------------------------------------------------------------+
|                                                            |
|  '가사' 카테고리를 정말 삭제하시겠습니까?                  |
|                                                            |
|  i 알림:                                                   |
|  이 카테고리에 속한 3개의 할일은 삭제되지 않으며,          |
|  '미분류' 상태로 변경됩니다.                               |
|                                                            |
|  [ 취소 ]                      [ 삭제 (bg-rose-600) ]      |
|                                                            |
+------------------------------------------------------------+
```

## 7. 반응형 레이아웃 전환 전략 (Summary)

| 뷰포트 너비 | 레이아웃 전략 | 주요 변화 요소 |
|------------|-------------|--------------|
| **Mobile** (320px~640px) | 단일 컬럼 (Stack) | 사이드바 -> 햄버거 메뉴/Drawer, FAB 사용, 카드 너비 100% |
| **Tablet** (641px~1023px) | 좁은 사이드바 고정 | 사이드바 아이콘+텍스트 간소화, 메인 영역 유동 너비 |
| **Desktop** (1024px+) | 와이드 2컬럼 | 사이드바 완전 노출 (240px), 메인 영역 max-w-5xl 중앙 정렬 |
