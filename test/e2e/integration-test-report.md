## 추가 관찰 사항

- **다크 모드 지원:** 헤더에 다크 모드 토글 버튼 존재
- **다국어 지원:** 한국어/영어/일본어 언어 전환 기능 존재
- **상태 자동 계산:** dueDate 기반 OVERDUE 상태가 조회 시점에 실시간 계산됨 (BR-06/08 준수)
- **카테고리 인라인 편집:** 카테고리 수정/삭제 버튼이 hover 시 표시됨 (group-hover 패턴)
- **접근성:** `aria-label` 사용 확인 (카테고리 추가 버튼 등)
